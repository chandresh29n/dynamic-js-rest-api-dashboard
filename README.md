# Dynamic JavaScript DOM Logic & RESTful API Client

## Project Overview

DynamicBoard is a responsive web-based user management
dashboard developed using HTML5, CSS3 and JavaScript ES6+.

The application retrieves live user information from a
public REST API and dynamically displays the results.

## Features

- Asynchronous REST API integration
- Fetch API with async/await
- Real-time user search
- Dynamic city-based category filtering
- Alphabetical sorting
- Favorite user management
- LocalStorage caching
- Persistent search and filter preferences
- Loading skeleton states
- Error banners and retry functionality
- Responsive mobile, tablet and desktop layouts
- Accessible interface and keyboard navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript ES6+
- Fetch API
- JSONPlaceholder REST API
- Browser LocalStorage
