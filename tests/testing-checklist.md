# Functional Testing Checklist

## 1. REST API Testing

- [ ] API successfully retrieves user data.
- [ ] API response is displayed correctly.
- [ ] Refresh button reloads user data.
- [ ] API errors are handled correctly.
- [ ] Retry button works after an API failure.

## 2. Search Testing

- [ ] Search by user name.
- [ ] Search by email.
- [ ] Search by company.
- [ ] Search by city.
- [ ] Search results update while typing.

## 3. Category Testing

- [ ] All Cities displays all users.
- [ ] Individual city filters work.
- [ ] Active category is highlighted.

## 4. Sorting Testing

- [ ] Name A-Z.
- [ ] Name Z-A.
- [ ] Company A-Z.
- [ ] Email A-Z.

## 5. LocalStorage Testing

- [ ] Add users to favorites.
- [ ] Remove users from favorites.
- [ ] Favorite information persists after refresh.
- [ ] Search preferences persist after refresh.
- [ ] Category preferences persist after refresh.
- [ ] Sorting preferences persist after refresh.

## 6. Loading and Error Testing

- [ ] Loading skeleton appears during requests.
- [ ] Loading skeleton disappears after requests.
- [ ] Error banner appears when API fails.
- [ ] Retry functionality works.

## 7. Responsive Testing

- [ ] Mobile layout.
- [ ] Tablet layout.
- [ ] Desktop layout.

## 8. Accessibility Testing

- [ ] Keyboard navigation.
- [ ] Visible focus indicators.
- [ ] Accessible form labels.
- [ ] Screen reader announcements.
- [ ] Sufficient text contrast.

## 9. Final Verification

- [ ] No JavaScript console errors.
- [ ] No broken links.
- [ ] All application features work.
- [ ] GitHub repository updated.
